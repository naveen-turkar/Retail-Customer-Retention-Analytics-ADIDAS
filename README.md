# Retail Customer Retention Analytics – ADIDAS

## Project Overview

This project focuses on analyzing customer retention and identifying key patterns related to customer churn, repeat purchases, loyalty, promotions, store performance, sales channel performance, and Customer Lifetime Value (CLV).

The analysis was performed using Power BI to transform customer data into meaningful insights and interactive visualizations.

## Project Objective

The objective of this project is to analyze customer behavior and retention patterns to understand the factors influencing customer churn and loyalty.

The project focuses on evaluating customer retention, repeat purchase behavior, promotion effectiveness, store and sales channel performance, and Customer Lifetime Value (CLV).

## Tool Used

- Power BI

## Analysis Performed

- Customer Churn and Retention Analysis
- Customer Segmentation
- Repeat Purchase Analysis
- Customer Loyalty Analysis
- Promotion Effectiveness Analysis
- Store Performance Analysis
- Sales Channel Performance Analysis
- Customer Lifetime Value (CLV) Analysis
